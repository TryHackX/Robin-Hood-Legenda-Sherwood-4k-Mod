Folder hd - grafika HD do moda SherwoodEngineFix (opis techniczny: docs\HD_MODE.md)
Ustawienia moda (grafika HD, interfejs, menu, VSync, filtr...) zmienia się w grze klawiszem F10.

TEGO UŻYWA GRA
  maps\<wariant>\*.hdmap    Mapy HD: 20 map w każdym z 4 wariantów AI (aomr, dat2, sgi, ultrasharp).
                            Własny format, nazwy plików to klucze treści - przeglądarka zdjęć ich nie otworzy.
  maps4k\<wariant>\*.hdm4   Mapy w natywnym 4K (4x oryginał, tylko wariant dat2, 3,3 GB). Gra używa ich przy zbliżeniu
                            powyżej 2,0 (na monitorze 2560x1440 od ok. 2,2; na 4K od 2,0), HDMaps4k=1 w SherwoodFix.ini.
                            Opcjonalne, w paczkach SherwoodHD-5-mapy-4k-a i -b. Robi je: tools/hd/upscale_4k.py,
                            potem tools/hd/make_maps4k.py
  sprites\<wariant>\        Dachy, drzewa, obiekty w HD (osobno dla każdego wariantu).
  sprites\_common\          Postacie i wszystkie animacje w HD (wspólne dla wariantów).
  sprites\_icons\           Ikony i znaczniki w HD: portret nad wybranym bohaterem, "Z" nad śpiącym, gwiazdki,
                            znaki zapytania, pierścień pod postacią. Brakujące ikony z nowych misji mod zapisuje
                            sam do work\runtime_frames\, a dorabia je:  python tools/hd/upscale_icons.py --model ultrasharp
  sprites\_between\         Klatki pośrednie animacji WSZYSTKICH postaci (ok. 3 GB, model RIFE; od 2026-11-15 ostre - każdy
                            piksel z jednej z dwóch klatek, bez mieszania). Włączanie w grze: F9 (albo HDInBetween=1
                            w SherwoodFix.ini). Usunięcie folderu wyłącza je całkowicie. between.q / between.v1.q = listy
                            jakości (nowy / pierwszy magazyn). Robi je od nowa:
                            python -I tools/hd/make_inbetweens.py --files Characters/ --jobs 3 --redo --sharp
                            python -I tools/hd/between_quality.py
  sprites\_between_more\    Druga próba par postaci, których _between nie przyjął (upadki, szybkie ciosy, schylanie;
                            ok. 11 400 klatek, 2026-11-22). Mod szuka pary najpierw w _between, potem tutaj.
  sprites\_between_anim\    Klatki pośrednie animacji POZIOMU (DATA\Animations: ptaki, kury, flagi, dym, muchy...) i
                            płynny tor lotu między ich krokami (2026-11-22). Oba foldery w SherwoodHD-4-klatki-posrednie-2.zip,
                            potrzebują moda 1.2.9 lub nowszego. Robi je kolejka:  tools\hd\queue_between.ps1,
                            potem:  python -I tools/hd/compact_between.py --store _between_anim --keep-all
                                    python -I tools/hd/compact_between.py --store _between_more

  menu\<wariant>\*.mhd      Tła menu (menu główne, opcje, wczytywanie...) powiększone tym samym modelem co mapy; gra pokazuje
                            je przy MenuZoom=1 i HDMenu=1. Nowe tła mod sam zbiera do work\menu_frames\, robi je:
                            python -I tools/hd/upscale_menu.py   (pliki .alias = to samo tło w menu otwartym w misji)
  menu\remake\*.mhd         Nowe tła menu (remake, na cały ekran 16:9) - mają pierwszeństwo przy HDMenuRemake=1
                            (F10 -> "MENU W HD"). Wstawia je:  python -I tools/hd/menu_remake.py import
  fonts\*.hdfont            Czcionki gry 2x większe (model SGI): napisy w misji, w menu i w oknach.
  menu_parts\*.hdp          Przyciski, pergamin odprawy, pieczęcie, portrety 2x większe (model SGI). Nowe obrazki mod
                            zbiera do work\menu_parts\, robi je:  python -I tools/hd/upscale_menu_parts.py
  minimap\classic\          Obrazek mapy obozu Sherwood z gry (leśna ścieżka) powiększony 4x (model dat2) - MinimapCamp=0.
  minimap\clean|parchment\  Otwarta minimapa zrobiona z obrazu HD poziomu (4x obrazka gry): clean = naturalne kolory,
                            parchment = zabarwiona jak stara mapa na pergaminie (domyślna). Gotowe pliki - gra niczego
                            nie generuje. F10 -> MINIMAPA - OBRAZ / WIELKOSC. Robi je:
                            powershell -File tools\hd\make_all_minimaps.ps1   (wszystko od zera)

REMAKE TEŁ MENU (gra tego nie czyta)
  remake\                   Tła do przerobienia przez AI do obrazów, zrzuty z układem przycisków, PROMPTY.txt (jak to
                            zrobić i prompty). Gotowe obrazy wrzuca się do remake\gotowe\ (NN_nazwa.jpg/png).
                            Robi to:  python -I tools/hd/menu_remake.py export

DO OGLĄDANIA I PORÓWNAŃ (gra tego nie czyta)
  maps_hd\<wariant>\*.png   Podglądy map HD z normalnymi nazwami: dokładnie te same piksele co w plikach .hdmap.
                            Robi je:  python tools/hd/hdmap_to_png.py            (wariant z SherwoodFix.ini)
                                      python tools/hd/hdmap_to_png.py --variants all   (wszystkie, ok. 0,7 GB każdy)
  maps_hd\_stare\           Nieaktualne próby (np. pierwsza mapa sprzed korekty kolorów). Można usunąć.
  maps_png\*.png            Oryginalne mapy gry (do porównań; także wejście dla modeli AI).
  menu_png\<wariant>\*.png  Podglądy teł menu HD (i _oryginal\ - tła z gry, remake\ - nowe tła).
  menu_parts_png\*.png      Podglądy przycisków, pergaminu, pieczęci i portretów HD (na szachownicy).
  minimap_png\*.png         Podglądy minimap HD (clean_ / parchment_<poziom>_<pora>_<klucz>.png).
  compare\                  Arkusze i animacje porównawcze: przed/po, warianty, klatki pośrednie.

DLA NARZĘDZI (gra tego nie czyta)
  models\, models_vfi\      Pobrane modele AI (upscaling; RIFE do klatek pośrednich).
  work\                     Kopie robocze banku sprite'ów i logi generowania.

Wariant w grze: F8 oryginał <-> HD, F7 / F6 następny / poprzedni wariant (albo HDVariant= w SherwoodFix.ini).
Klatki pośrednie (próba): F9 włącza i wyłącza; wybór jest zapamiętywany.
