Ready-made HD graphics for the SherwoodEngineFix mod — **no AI processing on your PC needed**. Requires the mod
**1.1.0 or newer** and the GOG edition of Robin Hood: The Legend of Sherwood.

The HD files are the 7 `SherwoodHD-*.zip` archives under **Assets** below (0.7–1.7 GB each). "Source code (zip)" /
"Source code (tar.gz)" are added by GitHub to every release automatically — only the mod's source code, not needed
to play.

## Installation
1. Install the mod first: `winmm.dll` and `SherwoodFix.ini` from
   [SherwoodEngineFix 1.1.0](https://github.com/TryHackX/Robin-Hood-Legenda-Sherwood-4k-Mod/releases/tag/v1.1.0) into
   the game folder (the folder with `Game.exe`).
2. Download the archives below — at least the three **required** ones (2.9 GB); everything is 6.4 GB.
3. Unpack **each** archive **into the game folder** (Windows: right-click → *Extract All…* → the game folder). They
   contain the `hd` folder; afterwards `hd\sprites\_common\` must hold `sprites.idx`, `sprites.dat` and `sprites.dat.2`.
4. Start the game. F6 / F7 switch the background variant, F8 compares with the original, F9 turns the in-between
   animation frames on and off, F10 opens the mod's settings.

Full step-by-step guide: [README → Installation](https://github.com/TryHackX/Robin-Hood-Legenda-Sherwood-4k-Mod#installation--the-complete-hd-version-step-by-step).

| Archive | Contents | |
|---|---|---|
| `SherwoodHD-1-postacie-a.zip` + `SherwoodHD-1-postacie-b.zip` | characters and all their animations, icons and markers | **required** (both) |
| `SherwoodHD-2-tla-dat2.zip` | map backgrounds, roofs, trees, objects, menu backgrounds — variant `dat2` (default, most faithful) | **required** |
| `SherwoodHD-3-klatki-posrednie.zip` | in-between frames of character animations (2× smoother animation, F9) | optional |
| `SherwoodHD-wariant-aomr.zip` | background variant `aomr` (contrasty, game-texture model) | optional |
| `SherwoodHD-wariant-sgi.zip` | background variant `sgi` (model for 90s pre-rendered game graphics) | optional |
| `SherwoodHD-wariant-ultrasharp.zip` | background variant `ultrasharp` (most added detail) | optional |

## What it is
The game's own pictures (all 20 maps, every sprite frame of the characters and objects, icons, menu backgrounds)
upscaled 2× with AI models, colours and brightness matched back to the original; the in-between frames were generated
with RIFE and checked automatically (pairs that failed the checks run as in the original game).

AI models: 4xNomos2_hq_dat2 and 2xAoMR_mosr by Phhofm (CC-BY-4.0), 4x SGI by ChrisNonyminus (GPL-3.0),
4x-UltraSharp by Kim2091 (CC-BY-NC-SA-4.0 — the `ultrasharp` variant and the icons: non-commercial use only),
RIFE by hzwer et al. (MIT).

Fan-made, non-commercial, for owners of the game. The original artwork belongs to its rights holders; this pack is
of no use without the game.
