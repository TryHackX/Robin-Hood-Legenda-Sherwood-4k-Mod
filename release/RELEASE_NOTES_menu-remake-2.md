Remade menu backgrounds for the SherwoodEngineFix mod (Robin Hood: The Legend of Sherwood, GOG edition) - **optional**.

Six backgrounds painted anew by an image AI after the original ones, filling the whole widescreen screen (no black
bars): main menu (also behind the question whether to quit), options, sound and graphics options, load / save, the
parchment screen and the credits. 2730x1536 each (the part of the screen the full-screen menus show, at 2x).

## Installation
1. The mod and the HD graphics first - see the [newest mod release](https://github.com/TryHackX/Robin-Hood-Legenda-Sherwood-4k-Mod/releases/latest)
   (mod 1.1.8 or newer: the credits and the quit question use these pictures too).
2. Unpack `SherwoodEngineFix-menu-remake-2.zip` **into the game folder** (next to `Game.exe`; Windows "Extract All" adds
   the archive's name to the path - delete that part). It adds `hd\menu\remake\` (6 pictures + 6 small `.alias` files).
3. In the game: F10 -> "MENU W HD (TLA, NAPISY)" -> "TAK, TLA Z REMAKE GDY SA" (the default) shows them; the other
   choices show the AI-upscaled original backgrounds or the original menus.

Replaces `SherwoodEngineFix-menu-remake-1.zip` (five backgrounds, without the credits).
How they were made (prompts, import): `tools\hd\menu_remake.py` in the repository.
